# SIAF: Sistema Inteligente de Adherencia Farmacológica
Este sistema está pensado para ayudar a personas con enfermedades degenerativas, problemas como puede ser el Alzheimer, o simplemente una mala memoria a mejorar su adherencia farmacológica y recobrar un poco de autonomía
